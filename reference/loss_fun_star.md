# Regularized log loss function

Regularized log loss function

## Usage

``` r
loss_fun_star(xdumm, p_bg, q_vec, y_vec)
```

## Arguments

- xdumm:

  Observed counts

- p_bg:

  Vector of open probability

- q_vec:

  Capturing probability vector

- y_vec:

  Observed counts

## Value

Regularized log loss
