# Internal evaluation use only – PACS Without Firth

Internal evaluation use only – PACS Without Firth

## Usage

``` r
our_method_no_firth(data_matrix_pos, data_matrix_neg, true_q_pos, true_q_neg)
```

## Arguments

- data_matrix_pos:

  Count matrix in foreground group

- data_matrix_neg:

  Count matrix in background group

- true_q_pos:

  Capturing probability vector for the foreground group

- true_q_neg:

  Capturing probability vector for the background group

## Value

P values for each cell
