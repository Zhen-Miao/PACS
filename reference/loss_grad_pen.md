# Gradient of penalized loss ( Invariant prior)

Gradient of penalized loss ( Invariant prior)

## Usage

``` r
loss_grad_pen(xdumm, p_bg, q_vec, inf_mat, wii_sqrt_X)
```

## Arguments

- xdumm:

  A design matrix, X

- p_bg:

  A value of open probability

- q_vec:

  A vector of capturing probability

- inf_mat:

  Information matrix

- wii_sqrt_X:

  sqrt(wii) as a vector times the design matrix

## Value

Gradient of penalized loss ( Invariant prior)
