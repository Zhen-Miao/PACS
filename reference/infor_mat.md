# Information matrix – original without Firth prior

Information matrix – original without Firth prior

## Usage

``` r
infor_mat(xdumm, p_bg, q_vec)
```

## Arguments

- xdumm:

  A design matrix, X with dummy variables

- p_bg:

  A vector of open probability

- q_vec:

  A vector of capturing rates

## Value

information matrix
