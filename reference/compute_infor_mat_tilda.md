# compute_information matrix tilda

compute_information matrix tilda

## Usage

``` r
compute_infor_mat_tilda(xdumm, p_bg, q_vec, y_vec)
```

## Arguments

- xdumm:

  A design matrix, X

- p_bg:

  open probability vector

- q_vec:

  A vector of capturing probability

- y_vec:

  A vector of observed open (1) or close (0) state for each cell, must
  match the length of q

## Value

information matrix tilda
